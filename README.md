# LearnSpanish
An app to help learn Spanish.

It must use the Web Speech API, built into the browser, which must be set to Spanish (Spain) and used for speech recognition. The application has a number of tests, which you select from the first menu, and which then prompt the user to speak to encourage recall. 

## Test 1: common verbs

This tests your recall for the most common Spanish verbs. The vocabulary is below. The English meaning (e.g. to have) is shown, and the user has to speak aloud the Spanish verb. Be permissive in what is accepted: the infinitive, the active or with or without the pronoun, doesn't really matter. The user can also say "don't know" to skip trying to guess. The application then shows the verb and speaks it aloud.

Ten words, chosen at random - but not repeated in one session - should be presented in the test. At the end the user gets a score out of ten, then returned to the main menu.
